# SintBot 1.3.0 website

This site describes the macOS / one Feishu group / Codex message route. Installation adds a separate exact-version package; setup and first use follow the versioned bilingual installation guide. Operation is foreground only.

Multiple groups, other platforms/model routes, whiteboards, the console and schedules are follow-up work. Existing installations retain their current version until a compatible migration exists.

Before deployment, verify the exact npm artifact and versioned public docs, run the bilingual generator/checks and review desktop/mobile pages. Copy `install.sh` unchanged from the audited product release. Do not publish before the package is available.
