执行器可选，模型也可选

按你的工作方式选择合适的模型

Claude Code、Codex 是编码执行器；Claude、GPT、GLM、MiniMax、DeepSeek 是背后的模型。为项目选择合适的组合。

  • Claude通过 Claude Code
  • GPT通过 Codex
  • GLMClaude Code · 自备 API Key
  • DeepSeekClaude Code · 自备 API Key
  • MiniMaxClaude Code · 自备 API Key
  • KimiClaude Code · 自定义端点
  1. 01

    群里就能切

    在群里选择已配置的模型，让下一轮用它开工。切换会开启新对话，项目文件和已保存的记忆保留。

  2. 02

    按项目配置，按任务选择

    每个群有自己的执行器和模型。Claude Code 可连接 Claude、GLM、MiniMax、DeepSeek 等兼容服务；Codex 使用自己的账号和模型配置。

  3. 03

    记忆比模型活得久

    把项目约定、决定和未完成事项写进 CLAUDE.md、AGENTS.md 等共享文件，留在本地。换模型后，新对话可以读取这些记录继续工作。

从对话到完整的工作流程

代码、设计与项目管理同一套工作流

把团队的聊天平台、设计工具和日常任务接到一起，围绕同一个项目持续协作。

  • 01

    飞书、Slack、企业微信

    接入团队原来就在用的群和频道，通过长连接工作，免公网 IP。在对话里发图、传文件，查看任务进度与结果。

  • 02

    生图、标注、原型预览

    沿用项目现有风格，生成或修改图片；在飞书画板上标注、按评论迭代，保留设计版本，并把交互原型分享给团队预览。

  • 03

    一个控制台管理所有群

    集中查看各群忙闲、实时活动、运行任务和消息队列；按项目管理模型、权限、插件与预览，随时查看进度或停止任务。

  • 04

    定时提醒与自动任务

    安排一次性或周期性的提醒、助手任务和脚本，让日常检查、数据汇总和报告按时回到项目群。

  • 05

    权限按群配置

    按群选择只读、开发或全信任权限，配置允许使用的工具。消息发出前遮盖密钥，个人信息的处理方式按群设置。

  • 06

    登录时接管浏览器

    浏览器任务遇到登录或验证时，群里会给出页面截图和接管入口。用手机或电脑完成操作后，助手沿用登录状态继续工作。

开始使用

把下一个项目接进群里

在自己的 Mac 上安装 SintBot，将项目接入飞书。准备 Node.js 22 及以上，以及已安装并登录的 codex，按安装指南完成配置。

npm · sintbot v1.4.10 PolyForm Shield macOS · 飞书 · Codex github.com/sintlab/sintbot
安装指南阅读使用说明

一行安装，再连接项目群

完整配置和准确的启动步骤见 1.4.10 安装指南。

复制一条命令即可安装。安装器自动检查环境、安装程序并验证结果。

curl -fsSL https://sintbot.com/install.sh | bash

  1. 01

    准备运行环境

    确认 Node.js 22 及以上，以及已安装并登录的 Codex，保留原有账号数据。

  2. 02

    独立安装

    复制上方命令，在终端执行；安装器自动验证程序包。

  3. 03

    连接一个群

    创建飞书自建应用，配置长连接，将一个群绑定到现有项目，按版本指南完成配置。

  4. 04

    启动并验证消息

    全新安装按指南复制一组首次启动命令，保持终端开启，再验证一条只读答复。

你可能想知道

开始之前把这些说清楚

SintBot 可以使用哪些模型？+
通过 Claude Code 使用 Claude，通过 Codex 使用 GPT；也可在 Claude Code 中配置兼容端点和自己的 API Key，接入 GLM、MiniMax、DeepSeek。Kimi 等兼容服务可使用自定义端点。
换模型之后，什么会保留？+
项目文件和已保存的共享笔记保留。切换会开启新对话；把决定和待办写进项目，下一位助手即可读取记录，接着推进。
SintBot 是什么？+
把项目群连接到自己机器上的 Claude Code 或 Codex 的编码助手。在群里派活，按任务选择执行器与模型，让代码、素材和已保存的项目记忆留在同一个项目里。
可以接入哪些聊天平台？+
SintBot 可接入飞书群、Slack 频道和企业微信群。每个群绑定自己的项目，任务进度和结果回到原来的对话里。
多个项目如何管理？+
每个群绑定独立的项目目录，配置自己的执行器、模型和权限。在控制台查看各群状态、正在执行的任务、消息队列和定时安排。
全部处理都在离线环境完成吗？+
不是。SintBot 和项目在本机运行，聊天平台及配置的模型服务仍需联网。模型请求遵循所选执行器的配置及服务商的数据政策。
安装需要准备什么？+
一台已安装 Node.js 22 及以上的 Mac、已安装并登录的 Codex，以及按安装指南配置好的飞书中国版应用。
