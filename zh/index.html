SintBot 1.3.0 · 首版范围

飞书单群里的编码助手。

在 Mac 上，SintBot 将一个飞书群连接到一个项目。群消息经内置核心启动 Codex 轮次，最终答复回到群里。

macOS · 一个飞书群 · Codex 消息路径

1.3.0 支持范围

先交付可用的核心路径。

支持 macOS

首版在 Mac 上验收；Linux 和 Windows 后续适配。

一个飞书群

一个群绑定一个本机项目；首版内置核心暂不支持一个服务接多个群。

Codex 消息轮次

在群里发任务，Codex 在绑定项目中工作并回复。建议先用只读权限，运行时保持前台终端开启。

后续迭代

逐步扩展更多能力。

飞书画板、多群、Slack、企业微信、管理控制台、定时任务和终端聊天不在首版内置核心支持范围。正在使用这些能力的安装应保持当前版本，等待兼容的升级路径。

在 Mac 上安装 1.3.0。

需要 Node.js 22 及以上，以及已安装并登录的本机 Codex。安装器保留已有全局安装和服务；不要用这个单群版本直接迁移多群安装。

curl -fsSL https://sintbot.com/install.sh -o /tmp/sintbot-install.sh
bash /tmp/sintbot-install.sh --dry-run
bash /tmp/sintbot-install.sh

常见问题

先把首版范围说清楚。

SintBot 是什么？

运行在自己机器上的项目群编码助手。1.3.0 首版内置核心路径支持 macOS 飞书单群中的 Codex 消息轮次。

现有多群安装能直接升级吗？

暂不能直接切到这个受限路径。请保持当前服务，等待兼容的多群升级与恢复方案。

画板和其他聊天平台包含在首版吗？

不包含。画板、Slack 和企业微信将在后续内置核心版本中完善。

哪里看安装说明？

按本页 1.3.0 安装指南操作：安装器把程序放到独立目录，再配置一个群、初始化全新状态并在前台启动。
