02 · How it works

From one sentence to a project task.

SintBot receives the group message, runs Codex in the bound project on your Mac and returns the answer. Feishu and the model service remain network services.

04 · Install

Install SintBot on your Mac.

The 1.3.0 package includes the built-in core. Prepare macOS, Node.js 22 or later and a working, signed-in codex. The installer does not install Node or sign in to Codex.

npm · sintbot v1.3.0 PolyForm Shield macOS · Feishu · Codex github.com/sintlab/sintbot

From your Mac to the group, in four steps.

Use the 1.3.0 installation guide for the full configuration and exact startup commands.

Download the installer, preview its actions with --dry-run, then run the same file. It installs into a separate release directory.

curl -fsSL https://sintbot.com/install.sh -o /tmp/sintbot-install.sh
bash /tmp/sintbot-install.sh --dry-run
bash /tmp/sintbot-install.sh

  1. 01

    Prepare your Mac

    Confirm Node.js 22+ and a working, authenticated Codex. Keep your current account data.

  2. 02

    Install separately

    Run the commands above. Existing global packages, configuration and services are left untouched.

  3. 03

    Connect one group

    Create a Feishu custom app, configure its long connection and bind one group to an existing project. Follow the versioned guide.

  4. 04

    Start and try a message

    Initialize fresh state only for a new installation, then start in the foreground. Keep the terminal open and verify a read-only reply.

05 · FAQ

Asked often, answered plainly.

What is SintBot?
A coding assistant that connects one Feishu group to a local project. In 1.3.0, Codex works on your Mac and returns its answer to the group.
What does 1.3.0 support?
macOS, Node.js 22+, one Feishu group and Codex, running in the foreground. Multiple groups, other model routes, Slack, WeCom, whiteboards, the console, schedules and other operating systems are not included.
Can I upgrade my existing installation?
Keep your previous version if you depend on capabilities outside this release. Installing a separate package does not migrate existing state; wait for a compatible migration procedure.
Does everything work offline?
No. SintBot and the project run on your Mac, but Feishu and your configured model service require a network connection. Model requests follow Codex configuration and the service provider’s data policy.
What do I need to install it?
A Mac with Node.js 22+, an installed and signed-in Codex, and a Feishu application configured according to the versioned guide. Use Feishu China edition; international Lark is not supported.
How is SintBot licensed?
SintBot is distributed under PolyForm Shield 1.0.0. The package includes its built-in core, the license and third-party notices. Model service access is configured separately.
